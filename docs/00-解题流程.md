# 00 新题诊断流程（遇到没练过的题，照着走）

> **总原则：考试是结果论 —— 没有输出文件 = 0 分。**
> 流程永远 5 步：**读题面 → 判题型 → 套模板 → 本地验证 → 交卷**。
> 宁可先跑出一个保底提交，再回来优化，绝不要卡在"想清楚"上拖到超时。

---

## 考场版：只用本地 35B 大模型（没有 Claude）时怎么问

> 定位：本地模型是「读题 + 出代码」的**副驾**，不是「跑代码」的 agent。
> 它只「文本进 → 文本出」，跑不了代码。分工：**它看题出码，你跑码、喂报错、核对提交。**
> 统一套路：喂「结构化摘要」不喂原始文件；每句都锁死防幻觉约束。
> 平时练习有 Claude 时用上面各步的「喂给 AI 的 prompt」也行；下面这套是考场专用（多了防幻觉约束）。

### 核心口诀：喂「结构化摘要」，别喂原始数据（上下文小不是问题）

37 万行 xlsx 是几百万 token，但一张 10 行的字段摘要才几百 token，4K 上下文都塞得下。
**上下文小不是瓶颈，喂错了东西才是。** 先自己用 pandas 扫一眼，压成下面这张卡片再喂。

**结构化摘要模板**（填空即用）：

```
【任务】<一句话>
【训练】<N 行 × M 列>：
  <列名> <类型> (<unique 数> unique)   例: <2 条样例>
  ...
  <目标列> <类型> (目标)               例: <样例>
  head: <头 1 行>
【测试】<M 行，字段同上/无目标列，注明有没有答案列>
【提交】<文件名>，<几列>：<列名1>, <列名2>, <提交列>（<值类型/范围/整数约束>）
【评分】<RMSE / Macro-F1 / accuracy ...>
```

**填好的例子**（练习2206 电影评分）：

```
【任务】根据用户观影行为+电影信息，预测用户对电影的评分
【训练】376353 行 × 5 列：
  user_id int (76107 unique)         例: 98234, 19357
  video_id int (1004 unique)         例: 13, 14
  name_en 文本 (979 unique)          例: "Alive!"
  description_en 文本 (803 unique)   例: "In this compelling documentary..."
  Rank int 1~5 (目标)                例: 1, 5
  head: [98234,13,"Alive!",...,1]
【测试】94089 行，字段同上，无 Rank 列
【提交】考生姓名_results.csv，3 列：user_id, video_id, predicted_rank（必须 1~5 整数，小数判 0 分）
【评分】RMSE，越小越好
```

就这几百字，题型（回归）、信号源（user_id/video_id 偏差）、陷阱（文本是电影级属性、必须整数）全露出来了。

**分工铁律**：本地模型「文本进→文本出」，跑不了代码。正确循环 = **它给码 → 你本地跑 → 报错原样贴回 → 它只改一处 → 你再跑**。别指望它「自己把整题做完」。

### 一次性准备：Ollama System Prompt（Modelfile）

考前 `ollama create` 好，之后每句话都不用重复约束：

```
你是 数据分析实操的做题助手。全程遵守：
1. 只输出离线能跑的代码，只能用 pandas/numpy/sklearn/lightgbm 这些本地已装好的库；
   禁止 torch/tensorflow/huggingface 下载模型、禁止 pip install、禁止联网请求。
2. 交代码前默读一遍，检查列名、索引、shape 是否对得上。
3. 读数据只用列名 + head/describe 摘要，不要假设不存在的字段。
4. 写 CSV 时列名和题目一字不差；中文用 utf-8-sig 或 gb18030。
5. 判题时先答「题型 + 为什么 + 模板号 + 3 个坑」，再给代码。
```

开长上下文：默认 4K/8K 会截断模板，任选一种开到 32768（显存紧张可降到 16384）：

```bash
/save qwen3

# B. Modelfile 固化（推荐，和上面的 system prompt 一起 bake 进去）
#     Modelfile 里再加一行：PARAMETER num_ctx 32768
ollama create ds-assistant -f Modelfile

# C. 环境变量兜底

```

### 5 个阶段 × 提示词（填空即用，直接复制把 `<>` 填了）

| 阶段 | 喂什么（都只喂摘要，不喂全量） | 要它输出什么 |
|---|---|---|
| 0 读题 | 摘要卡片 | 任务/字段/提交格式/评分/规模 + 初判题型 |
| 1 判题型 | 卡片 + 判题规则 | 题型 + 模板号 + 为什么 + 3 个坑 |
| 2 看数据 | 每列 unique/缺失 + head(3) + describe | 哪些是泄漏/废特征，哪些是信号 |
| 3 出代码 | 题型 + 本地模板全文 | 可跑代码，先特征后模型 |
| 4 验证 | 你跑出的分数 + 预测/答案前几行 | 为什么分低，只改一处 |
| 5 交卷 | 提交格式原文 + 你的输出头几行 | 逐项比对的不一致清单 |

#### 阶段 0 — 读题（5 分钟）：抄 5 项，别让模型猜

```
读题。题目原文如下：
<贴任务描述、字段说明、提交格式、评分方式、数据规模原文>

请用一行一项提取：
1) 任务=  2) 训练字段=  3) 提交格式(列名一字不差)=  4) 评分方式=  5) 规模=
并初判：回归 / 二分类 / 多分类 / 多标签 / 相似检索 / 文本对 / 问答 / 文本回归 中的哪一种。
```

#### 阶段 1 — 判题型（5 分钟）：核心，专治「没见过的新类型」

把三个「看着像 A 其实是 B」的坑直接写进 prompt，逼模型先排查：

```
这是 数据分析实操题，先别写代码，先判题型。
【任务】<原文>
【提交格式】<原文，含列名和示例>
【评分方式】<原文，如 Macro-F1 / accuracy / RMSE>
【训练字段】<列名+类型>
【测试字段】<列名，注明测试集有没有答案列>

判题规则（务必遵守）：
- RMSE/MSE → 回归；accuracy 或单标签 F1 → 分类；输出是一批 ID 且评 Macro-F1 → 相似检索；
  「文章+问题→能否回答」→ 问答生成；文本打分 → 文本回归。
- 三个经典陷阱先排查：
  ① 看着像分类、但标签其实由文章内容决定 → 是问答不是分类；
  ② 输出 30~50 个 ID、评 Macro-F1 → 是检索不是分类；
  ③ 分数藏在特征里（恒值列/长度泄漏）→ 要特征工程，不是换模型。

输出：题型 + 对应模板号 + 为什么 + 这题最可能的 3 个坑。
```

#### 阶段 2 — 看数据（10 分钟）：找信号源和泄漏特征

只喂摘要，不喂全量：

```
这是 <题型> 题。下面是数据 schema 摘要：
<每列：名称 / 类型 / 缺失率 / unique 数；再贴 head(3) 和 describe()>

请指出：
1) 哪些列是泄漏特征（恒值、ID、和答案列同名或高相关）→ 要删；
2) 哪些列是最强信号；
3) 复杂字段要不要特殊处理（逗号分隔 / json / 多表 / 图片哈希）。
```

#### 阶段 3 — 出代码（主战场，20~30 分钟）

**关键技巧**：模板就在本地硬盘，贴给模型当骨架，比让它凭空写可靠得多：

```
题型=<>，照着下面模板改。模板代码：<贴对应模板 01~10 全文>
- 训练=<路径>，测试=<路径>；特征列=<...>，目标列=<...>，ID列=<...>
- 评分=<...>，提交列名=<...>（一字不差），输出文件名=<...>

硬约束：只 pandas/numpy/sklearn/lightgbm，不下载模型，不联网。
代码里用 print 打出 X.shape 和预测 head。分两步给：先特征工程，再模型+写文件。
```

#### 阶段 4 — 本地验证（5 分钟）：分低就回阶段 0

```
我本地跑出分数 <x>。预测前几行：<贴>，答案前几行：<贴>。
帮我诊断为什么分低：题型判错？评分口径不对？还是特征问题？只改一处，先别大改。
```

#### 阶段 5 — 交卷比对（3 分钟）

```
题目提交格式原文：<贴>
我的输出文件头几行：<贴>
逐项比对：列名是否一字不差？行数是否=测试行数？值是原始标签还是数字编码？文件名？编码？
列出所有不一致，我改完再交。
```

### 本地模型 3 个必防坑 + 对策

| 坑 | 对策 |
|---|---|
| **幻觉 API / 让你下载模型** | System prompt 锁死「只 sklearn/lightgbm」，每句再重复「不下载不联网」 |
| **代码跑不通** | 让它「分步输出 + print shape」；你跑，**报错原样贴回去**，一次只改一处 |
| **上下文溢出 / 幻觉字段** | 只喂列名 + head/describe/unique，绝不贴全量 CSV；不存在的列它会编，要它「默认读文件列名」 |

## 第 0 步：读题（抄出 5 个必填项）

拿到题先打开 docx，把下面 5 项抄出来。**后面所有判断都靠这 5 项，不是靠数据长啥样。**

1. **题目任务** —— 要预测什么（一句话）
2. **训练/测试字段** —— 每列叫什么、什么类型（文本？数值？图片哈希？）
3. **提交格式** —— 结果 CSV 的**列名**（docx 白纸黑字写，抄错=0 分）
4. **评分方式** —— Macro-F1 / Micro-F1 / accuracy / RMSE / MSE（docx 里写）
5. **数据规模** —— 训练/测试各多少行

### 喂给 AI 的 prompt（直接复制，把 `<>` 填了）

```
这是 数据分析实操题，帮我判题型、套模板、给能跑的代码。
【题目任务】<一句话，从 docx 抄>
【训练字段】<列名 + 各一两条样例>
【测试字段】<列名，注意测试集里有没有答案列>
【提交格式】<docx 里"提交格式"原文，含列名和示例>
【评分方式】<docx 里"评分方式"原文，如 Macro-F1 / accuracy / RMSE>
【数据规模】<训练 N 行 / 测试 M 行>

请输出：
1) 这是什么题型，对应模板几号
2) 直接给我完整可跑的代码（离线、不联网、不下载模型）
3) 这题的关键坑（评分口径 / 输出格式陷阱 / 泄漏特征 / 文本是否需要分词等）
```

## 第 1 步：判题型（3 问定生死）

**关键：先看「目标变量 + 评分 + 提交格式」，别看数据长啥样。**
（最容易踩坑：看着像分类，其实是检索/QA——见文末三个真实案例）

### 第一问：目标变量是什么形态？

| 目标变量形态 | 题型 | 模板 | 典型评分 |
|---|---|---|---|
| 连续数值 | 回归 | ④ 表格回归 / ⑩ 文本回归 | RMSE / MSE |
| 单个类别标签 | 分类 | ① 表格二分类 / ② 文本分类 / ⑦ 表格多分类 | accuracy / 某类 F1 / Macro·Micro-F1 |
| 多个类别（逗号分隔 / 多列 one-hot） | 多标签分类 | ③ | 各标签 Macro-F1 / Micro-F1 |
| 一批 ID 列表（30~50 个） | 相似项检索 | ⑥ | Macro-F1 |
| 两两配对（A vs B）判相似 | 文本对相似度 | ⑤ | 预测=1 的 F1 |
| 问题 + 文章 → 能否回答 | 问答判定 | ⑨ | accuracy |
| 文本 → 连续打分 | 文本回归 | ⑩ | MSE |

### 第二问：特征（X）是什么类型？

- **结构化表格**（数值/类别列）→ ①④⑦⑧
- **纯文本** → ②⑤⑨⑩
- **图片 Phash + 文本** → ⑥（但注意：图片哈希常常是废特征，见文末案例 2）

### 第三问：评分方式在 docx 里怎么写的？

- `RMSE / MSE` → 回归
- `Macro-F1`（输出是一批 ID）→ 相似项检索
- `accuracy` / `某类 F1` → 二分类 / 问答
- `Macro-F1 / Micro-F1`（输出是单类别）→ 多分类 / 多标签

> 三个问题问完，题型基本锁定。锁不定就把「第 0 步」那 5 项填进 prompt 喂 AI，让它判。

## 第 3 步：本地验证（绝不要裸奔交卷）

练习文件夹里一般有 `test-Ans.xlsx` / `test_results.csv` 这种**带答案的测试集**。写完预测，先自己算一遍分数再交：

```python
# 通用自评：把预测结果和答案列对齐，按评分方式算
import pandas as pd
from sklearn.metrics import f1_score, accuracy_score, mean_squared_error
out = pd.read_csv('你的结果.csv')                       # 你的预测
ans = pd.read_excel('test-Ans.xlsx')                    # 带答案的测试集
m = out.merge(ans[['ID', '答案列']], on='ID')
# 分类：f1_score(m['答案列'], m['预测列'], average='micro'/'macro'/...)
# 回归：mean_squared_error(...)
```

**如果本地分很低，回到第 0 步重读题面** —— 十有八九是题型判错或评分口径没对上，不是模型没调好。

## 附：三个「看着像 A、其实是 B」的真实坑（都踩过）

1. **练习2406 阅读理解多选** —— 看着像「文本多分类」，其实标签由 article 内容决定、和问句措辞无关，是**问答/生成式**（模板⑨）。套文本分类只有随机分 0.25，用 flan-t5 零样本到 0.92。
2. **练习2303 相同产品** —— 看着像「分类」，其实输出 30~50 个 ID、评 Macro-F1，是**相似项检索**（模板⑥）。而且图片 Phash 是**废特征**（不同卖家同商品用不同图），真正信号在标题 char 相似度。
3. **练习2306 AI 识别** —— 题型没错是文本二分类，但**分数在 length 泄漏特征**上（AI 文本恒 =1024 词），不在语义。特征是王道，不是模型。
4. **练习2206 电影评分** —— 表格里有 name_en/description_en 文本列，看着像「文本回归」（模板⑩），但文本是**电影级属性**（训练集只有 ~800 个不同值），且测试集 998 部电影 100% 都在训练集见过 → 文本是废特征，本质是**协同过滤评分预测**（全局均值 + 用户偏差 + 电影偏差，带收缩），连续 RMSE 1.393。**再坑一层：docx 要求 predicted_rank 必须是 1~5 整数（「不可是实数，例如4.2」），输出小数直接 0 分** —— 所以先算连续预测、最后 round 成整数（round 后 1.424，官方几何平均 1.526）。别被文本列骗去套 BGE 逐行编码（47 万行、巨慢）。

> 一句话记住：**判题型看「输出 + 评分」，不看数据长相；找分数看「泄漏特征 + 信号源」，不盲目堆模型。**
